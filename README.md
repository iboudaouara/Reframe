# Reframe

[![Download on the App Store](https://img.shields.io/badge/Download_on_the-App_Store-black?style=for-the-badge&logo=apple)](https://apps.apple.com/ca/app/reframe/id6756591868)

Reframe is a journaling tool designed to help users analyze their thoughts.

## About the App

Reframe helps you step back from immediate reactions and analyze situations objectively. By journaling, you can identify patterns and "reframe" your perspective on daily events.
